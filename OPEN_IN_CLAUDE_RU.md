# Как передать дальнейшую разработку Claude Code

Проект: **https://github.com/REDLAIN228/Program**. В репозитории находятся исходники, тесты, assets, профили-адаптеры, инструкции и полный контекст передачи. Claude Code нужно открыть **в папке этого проекта**: ссылка сама по себе не передаёт доступ к файлам компьютера.

## Если пользуешься терминалом

Установи и авторизуй Claude Code по его официальной инструкции. Затем:

```sh
git clone https://github.com/REDLAIN228/Program.git
cd Program
git switch -c claude/next-redlain
claude
```

Если папка Program уже существует, не клонируй поверх и не делай reset/clean: сохрани свои изменения и открой существующую копию. Если предпочитаешь ZIP, скачай весь проект с GitHub и открой распакованную папку в Claude Code. Текущий рабочий рисунок и `%LOCALAPPDATA%\AnimeDrawer` отдельно сохраняются пользователем; не отправляй API-ключи.

Вставь в Claude Code этот стартовый промпт:

```text
Продолжи разработку REDLAIN DRAW ENGINE из текущего репозитория.
GitHub: https://github.com/REDLAIN228/Program

Прочитай CLAUDE.md, docs/CLAUDE_HANDOFF_RU.md и полностью
docs/CLAUDE_TASK_RU.md. Это моё точное задание на следующий этап.
Прочитай также docs/HANDOFF_VERIFICATION_RU.md и документы проверок 3.0.
Не сбрасывай актуальный HEAD на старый baseline.

Изучи исходники и запусти доступные тесты, затем реализуй задание:
упрости интерфейс и убери лишние/нерабочие элементы по результатам аудита;
сохрани рабочий ввод, профили, проекты и Resume; измеренно улучши скорость
и качество рисунка; сделай новый цельный UI, анимации запуска, раскрытия,
скрытия, компактного режима и переключений; анимированный фон и своего
реактивного ассистента-художника с 3D/2.5D-эффектом.

Ассистент и прогресс должны отражать реальные события. Анимации не должны
мешать мыши, безопасности, калибровке и производительности Roblox.
Никаких заглушек, фиктивного прогресса, удаления пользовательских данных,
отключения проверок ради скорости или переписывания приложения с нуля.
Не останавливайся на плане/макете: интегрируй код, проверь его, сравни
скорость и качество, собери Windows-дистрибутив в Windows-среде и дай
инструкцию. Ограничения среды и непроверенные пункты укажи честно.
```

**Полный промпт** со всеми критериями: [docs/CLAUDE_TASK_RU.md](docs/CLAUDE_TASK_RU.md). Именно его следует прочитать и выполнить, а короткое сообщение выше служит входом. Файл **CLAUDE.md** автоматически даёт Claude Code контекст при работе из корня.

## Что передано и что пока не сделано

[Передача проекта](docs/CLAUDE_HANDOFF_RU.md) описывает существующую архитектуру, рабочие модули, историю ошибок, измерения и ограничения. [Проверки пакета](docs/HANDOFF_VERIFICATION_RU.md) фиксируют доступные тесты.

В этой передаче подготовлены **исходники и задание**. Новый ассистент, анимированный фон, полная замена UI и последующая оптимизация — следующая работа Claude, они не выдаются за уже реализованные функции.

Для запуска существующей 3.0 на Windows: **run.bat**. Для EXE: **build.bat** на Windows; результат — вся папка `dist\RedlainDrawEngine`, включая `_internal`. [Windows workflow](https://github.com/REDLAIN228/Program/actions/workflows/windows.yml) описывает автоматическую сборку при push в main, если Actions включены и запуск разрешён. Его успех и наличие скачиваемого артефакта проверяй по конкретному запуску; исходный ZIP не является готовым EXE.
