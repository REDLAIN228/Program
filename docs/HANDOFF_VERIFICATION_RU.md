## Состав передачи

- **CLAUDE.md** — постоянный контекст в корне, правила сохранения данных, безопасности ввода и честных измерений.
- **OPEN_IN_CLAUDE_RU.md** — как клонировать/открыть проект, короткий стартовый промпт, команды запуска/сборки.
- **docs/CLAUDE_HANDOFF_RU.md** — архитектура, уже реализованные функции, ограничения, история ошибок, оставшиеся задачи и измеримые идеи оптимизации.
- **docs/CLAUDE_TASK_RU.md** — полный точный промпт на упрощение программы, рабочий UI, ускорение/качество, анимации и собственного ассистента.
- **docs/HANDOFF_VERIFICATION_RU.md** — этот протокол.
- Все отслеживаемые исходники, существующие тесты/fixtures, assets, run.bat/build.bat, requirements и прежние отчёты остаются в архиве проекта.

Пакет исходников формируется из опубликованного commit командой `git archive`. В нём нет локального venv, API-ключей, пользовательского каталога проектов, файлов .git или фиктивного EXE. ZIP проверяется по CRC и совпадению исходников/документов с commit. Скачиваемый GitHub ZIP привязывается к точному commit; его доступность проверяется отдельно после push. Он может иметь другую упаковку/корневое имя, чем локальный git archive, при одинаковых файлах.

## Не заявляется выполненным

- Windows EXE не собирался в Linux. `build.bat` и Windows workflow существуют; ожидаемый результат — вся папка `dist/RedlainDrawEngine` с `_internal`. Успех конкретного Windows CI не подтверждён в этой сессии.
- Живой Roblox, регистрация быстрых мазков, DPI/SendInput и серверное отключение здесь не проверялись. Нативный сценарий: [WINDOWS_ROBLOX_TEST_RU.md](WINDOWS_ROBLOX_TEST_RU.md).
- Живой API Commons недоступен по сетевой политике среды. Контрактные тесты интеграции не заменяют живой запрос. api.github.com также не разрешён текущей политикой; статус Actions не выдаётся за успешный.
- Benchmark в docs/v3-benchmark.json — ранее выполненное измерение 3.0, не новый замер передачи и не результат Roblox. Алгоритмы сейчас не менялись, поэтому benchmark не пересчитывался ради обновления документов.
- Claude Code не получил автоматический доступ к компьютеру/учётной записи пользователя. Для продолжения нужно открыть репозиторий в авторизованной пользователем сессии Claude Code и передать стартовый промпт.

Дальнейшая разработка и приёмка подробно заданы в [CLAUDE_TASK_RU.md](CLAUDE_TASK_RU.md). Пользовательские данные и незавершённые рисунки нужно сохранять отдельно от передачи исходного репозитория.
