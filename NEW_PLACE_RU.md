# Новый плейс: всплывающая RGB-палитра

Этот профиль предназначен для присланного интерфейса с большим белым холстом посередине, цветным кругом под холстом и числовым размером кисти. Старый профиль с HSV-кольцом и бесплатным ползунком остаётся отдельным.

## Как запустить

1. Закройте прежнюю копию программы через меню плавающей иконки → «Выход». Распакуйте обновление в отдельную папку и запустите `run.bat`.
2. Откройте новый плейс. Игровая область должна иметь размер **1366×768**, как на скриншотах. Нажмите в игре **«Сбросить масштаб»**. Сохраните расположение панелей и разрешение холста как на снимке; белый холст должен быть пустым, активный слой — видимым.
3. В ANIME DRAWER откройте **Drawing Settings → НОВЫЙ ПЛЕЙС · RGB v4 · 1366×768**. Выберите окно Roblox. Метка v4 помогает проверить, что запущено обновление. Профиль сохранится отдельно; выбирать точки вручную не нужно. Для исправления рамки доступен **CALIBRATE → Новый плейс · RGB v4**.
4. Оставьте **Непрозрачность 100%** и **Задержка игры 250 ms**. В новом интерфейсе настройка непрозрачности не показана, поэтому полупрозрачный режим для этого профиля не включён. Начните со скорости **Normal**.
5. Закройте палитру тем же цветным кругом, затем нажмите **TEST DRAW**. Программа сама откроет её для RGB и закроет перед линией. Должны появиться три короткие полоски: чёрная, красная, зелёная. Красная толще остальных. Подтвердите результат только если линии аккуратные и находятся на белом холсте.
6. Удалите тестовые полоски вручную. В **Image Import → IMPORT IMAGE** выберите картинку, стиль **Custom**, затем **PREVIEW → RUN**. Формат и масштаб рисунка задаются в Drawing Settings. Захват персонажа из старого плейса здесь не настроен.

**F8** — пауза/продолжение, **F9** — остановка. Во время ввода не трогайте мышь и клавиатуру. При смене разрешения, масштаба холста или расположения элементов сначала повторите настройку и TEST DRAW.

**Автопауза включена:** при сбое управления или отсутствии ожидаемого следа программа сохраняет запуск и ждёт F8. Восстановите игру и тот же холст, затем продолжите. Подробности и ограничения: [AUTO_PAUSE_RU.md](AUTO_PAUSE_RU.md).

## Что делает профиль

В профиле v4 программа нажимает справа от числа и выполняет одну последовательность: **End → Backspace → ввод нужного числа → Enter**. Клавиши удаления и Enter отправляются через scan-code пакеты стандартного Windows SendInput. Проверка пустого поля между удалением и вводом убрана: в v3 она могла ошибочно остановить программу, хотя число уже было удалено. Теперь проверяется итоговый цвет по образцу и размер по числу после Enter. Если значение не принято, программа повторяет ввод с выделением текста мышью внутри поля; при повторном несовпадении останавливается до штриха. Это работает для RGB и размера кисти. Профили v1/v2/v3 обновляются с отменой подтверждения TEST DRAW. Ошибочный размер 0 исправляется до начала штриха.

Паузы при наборе и нажатии на поля сокращены. Для двузначного числа суммарная заданная пауза между событиями клавиатуры составляет 0,70 с вместо 1,47 с в v3; перемещение, проверка результата и задержки самой игры добавляют время. Неизменные подтверждённые настройки используются повторно.

Тесты пропускают реальные пакеты генератора SendInput через модель числового поля: старое значение удаляется, цифры вводятся, результат применяется только после Enter. Модель игнорирует виртуальные клавиши редактирования, но принимает scan-code пакеты; отдельная проверка подтверждает остановку до рисования, если Enter не сработал. Также проверены повторный ввод и потеря фокуса. Эти модели не подтверждают работу на конкретном Roblox-клиенте: для неё нужен TEST DRAW на Windows.

- Вводит R, G, B числами. Уже совпадающие компоненты не набираются повторно; подтверждённый неизменный цвет не вызывает открытия палитры на каждом штрихе.
- Проверяет образец выбранного цвета, закрытие палитры и отображаемый размер кисти. Неподтверждённый размер не используется для рисования.
- Вводит размер в белое поле. В планах доступны размеры **1, 2, 4, 8, 16, 32**; это набор профиля, а не утверждение о максимуме игры. Если поле ограничивает размер, программа остановится при несовпадении числа.
- После ввода чисел выбирает обычную кисть. Слои, фигуры, масштаб, разрешение, другие инструменты, сохранение, отмена и удаление остаются под ручным управлением.
- Использует прежний подвод вдоль начала линии и отпускание мыши между штрихами.

Координаты заданы по скриншотам и проверяются в Linux на модели интерфейса. Это не проверка работы нового плейса на Windows: её выполняет TEST DRAW на вашем компьютере. Изменение DPI или размера окна блокирует ввод; автоматического масштабирования координат нет.

## Если возникла ошибка

Диагностика находится в `%LOCALAPPDATA%\AnimeDrawer\logs`:

- `controls.json`, `controls.png` — RGB или открытие/закрытие палитры;
- `brush-size.json`, `brush-size.png` — чтение размера;
- `test-draw.json`, `test-draw-after.png`, `test-draw-difference.png` — лишние следы на тесте.

При пропущенных нажатиях увеличьте задержку игры до **350 ms** и повторите тест на чистом холсте. Если цвет или размер не подтверждаются, сохраните эти файлы для диагностики.

Сообщение «Не удалось очистить числовое поле. Новое число не вводилось» относится к старой версии. Если видите его снова, полностью закройте старую копию и проверьте наличие метки **RGB v4** в новой.
