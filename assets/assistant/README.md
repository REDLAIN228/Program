# REDLAIN Assistant — исходники персонажа

Оригинальный персонаж-робот-художник, созданный для REDLAIN DRAW ENGINE 4.0. Не основан на чужом персонаже, emoji, GIF или стоковой графике.

- **Источник:** векторная QPainter-сцена в `app/ui/assistant.py` (голова с визором, антенна-индикатор, корпус с эмблемой R, двухзвенная рука с карандашом, мольберт). Персонаж рисуется кодом в каждом кадре, поэтому отдельные растровые файлы приложению не нужны.
- **PNG в этой папке** — эталонные рендеры поз (`idle`, `preparing`, `planning`, `drawing`, `paused`, `error`, `finished`), сгенерированные тем же кодом: `python tools/render_assistant.py`. Используются для документации и проверки внешнего вида.
- **Техника:** 2.5D — слоистая 2D-иллюстрация с градиентами объёма, контурным красным светом, контактной тенью и параллаксом по глубине слоёв. Это **не 3D-модель**; GPU, OpenGL, Qt Quick и загрузка моделей не требуются.
- **Лицензия:** часть проекта REDLAIN DRAW ENGINE; распространяется вместе с программой на тех же условиях, что и её исходный код (решение о публичной лицензии — за владельцем репозитория). Сторонних материалов нет.
