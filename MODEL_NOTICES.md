# Local OpenCV model notices

The optional CPU detector uses the frontal-face and eye Haar cascades shipped with the pinned opencv-python-headless wheel. These are trained cascade models, not an anime/body/hand recognition model. The optional Full Character mode also uses the HOG/SVM default pedestrian detector compiled into OpenCV. Hands/clothes regions derived from a body box are heuristics, not additional trained models. No models are downloaded at runtime. XML files retain their original copyright and licence headers.
