# REDLAIN DRAW ENGINE 3.0 — как пользоваться

Это обновление существующего Anime Drawer. Запуск: распакуйте **весь** ZIP в обычную папку и дважды нажмите `run.bat`. Нужен Windows 10/11 x64 и Python 3.11–3.13 x64. Первый запуск установит зависимости. Готового EXE в исходном ZIP нет. На Windows его можно собрать через `build.bat`: результат `dist\RedlainDrawEngine\RedlainDrawEngine.exe`; переносите всю папку, включая `_internal`.

Старые профили, изображения и настройки остаются в `%LOCALAPPDATA%\AnimeDrawer`. Это имя папки специально сохранено. Новые проекты находятся внутри `projects`; при переносе на другой компьютер копируйте **всю** папку `projects` вместе со скрытой `.assets`. Один `project.json` без ресурсов не переносит рисунок.

## Куда нажимать

| Раздел слева | Для чего |
| --- | --- |
| Dashboard | Импорт, текущий проект, последние работы и CONTINUE YOUR MASTERPIECE |
| Workspace | Большой Preview; справа выпадающий список Image / AI, Human Engine, Detail Priority, Drawing Settings, Smart Canvas Fill |
| Live Drawing | LIVE ART CORE: настоящие завершённые мазки, активная траектория, этап и оценка оставшегося времени |
| Discover | Реальный поиск Wikimedia Commons, подборки-запросы, избранное, импорт |
| Projects | Сохранённые проекты: открыть или продолжить |
| Settings | LOCAL CANVAS, TOOLS, AI SETTINGS, калибровка скорости и прежние инструменты |

Верхняя панель проекта: **Save Project**, **Pause & Save**, **Resume**, **Save As**, **Delete Checkpoint**. Снизу остаются RUN, PAUSE / RESUME · F8, STOP · F9. Крестик окна сворачивает приложение в плавающую иконку R. Для полного выхода используйте её меню «Выход»: приложение дождётся сохранения.

## Первый рисунок

1. Сначала откройте **Settings → TOOLS → LOCAL CANVAS**, выполните **TEST DRAW**, проверьте линию и очистите тестовый холст.
2. В **Workspace → Image / AI** нажмите IMPORT IMAGE. Можно перетащить файл. Для обычного импорта API не нужен.
3. В **Human Engine** выберите **Human 3.0 → BALANCED**. FAST упрощает детали и использует меньше цветов; MASTERPIECE сохраняет больше мелких областей. Legacy и Vector 2.0 доступны для сравнения и старых настроек.
4. В **Drawing Settings** выберите проверенный профиль, **Normal**, непрозрачность **100%**, таймер **Unlimited**. Для нового плейса доступен прежний RGB-профиль; для старого — бесплатный ползунок 1–256. Донатная вкладка и инструменты 6–8 старого плейса исключены.
5. Нажмите PREVIEW. DRAW PREVIEW показывает рассчитанные мазки; список виртуальных слоёв позволяет посмотреть отдельный художественный этап. Статистика содержит реальное число мазков и оценку времени.
6. Нажмите RUN. Проект автоматически сохраняется **до первого ввода**. Программа скроет свои окна, выберет кисть и цвета, затем начнёт рисунок. Мышью во время исполнения управляет программа.

Для Roblox подготовьте пустой белый игровой холст, одинаковые права Roblox/программы и рабочие F8/F9. Заново выполните CHECK BRUSH SIZE и TEST DRAW после смены интерфейса, DPI или калибровки. Готовые точки привязаны к клиентской области 1366×768 и не подходят автоматически любому разрешению. Подробности: [новый RGB-плейс](NEW_PLACE_RU.md), [старый плейс](ROBLOX_START_RU.md).

## Во весь холст и с детализацией

В Drawing Settings выберите **Формат → Весь холст**, **Масштаб → 100%**. В Human Engine — **MASTERPIECE** или BALANCED для более короткой работы. Нажмите PREVIEW заново.

Если пропорции картинки отличаются от холста, есть два варианта: включить **«Заполнить кадр обрезкой»** (часть краёв исходника обрежется) или оставить всю картинку и оформить добавленные поля через Smart Canvas Fill. На экране 534×530 нельзя физически нарисовать 1920×1080 независимых пикселей: MASTERPIECE допускает анализ до 1920 px, но реальный след ограничен игровым холстом и минимальной кистью. Начинайте с качественного исходника; увеличение маленькой картинки не восстановит отсутствующие детали.

Старое меню «Качество» относится к Legacy/Vector; при Human 3.0 оно отключено. Детализацией управляют FAST/BALANCED/MASTERPIECE. Полупрозрачность меньше 100% действительно меняет кисть, если профиль это поддерживает, но пересекающиеся мазки становятся темнее; для точного копирования используйте 100%.

## Как ускорить

1. Сначала FAST либо BALANCED: сокращение числа мазков обычно важнее голой скорости курсора.
2. Новые скорости: **Agile · 8**, **Rapid · 9**, **Sprint · 10**; прежние Safe, Normal и Turbo сохранены.
3. На чистом игровом холсте запустите **Settings → SPEED CALIBRATION · real canvas**. Она действительно рисует четыре длинные линии и измеряет их регистрацию по снимку. Согласитесь только на тестовом/пустом участке, затем очистите его вручную.
4. Используйте предложенную прошедшую скорость. Более редкая отправка точек включается только для совпадающей калибровки и успешно измеренного режима. Без этого сохраняются осторожные интервалы. При ошибке ввода приложение возвращает консервативную выборку.
5. Задержку игры сначала оставьте **250 ms**. Если поле не принимает цифры или цвет не подтверждается, увеличьте задержку; слишком короткая задержка даёт пропуски независимо от скорости мыши. После смены параметров пересчитайте PREVIEW.

Универсального обещания скорости нет: длительность зависит от API интерфейса игры, цветов, размеров кисти и формы рисунка. [Измеренный локальный результат](docs/V3_VALIDATION_RU.md) — примерно 2,3–2,9× для FAST относительно Vector 2.0 на трёх одинаковых маленьких примерах; это не замер Roblox.

## Сохранить и продолжить завтра

1. Нажмите **Pause & Save**. Текущая кнопка мыши отпускается; частично выполненный неподтверждённый мазок остаётся для повторения. Подтверждённые мазки сохраняются с точными индексами.
2. Дождитесь надписи **Saved · выполнено/всего**. При SAVE ERROR не закрывайте приложение до устранения ошибки. Автосохранение также работает каждые 30 секунд, на границах этапов, при паузе и завершении. Даже во время длинного мазка сохраняется последний полностью подтверждённый курсор, а не его случайная середина.
3. Выйдите через меню иконки. На следующий день откройте Dashboard → **CONTINUE YOUR MASTERPIECE** или Projects → Resume нужной работы.
4. Откройте **тот же сохранённый холст в игре**. Совпасть должны игра, размер окна, DPI, масштаб и расположение холста. Программа проверит геометрию и доступный снимок.
5. Если состояние нельзя установить уверенно, появится сравнение сохранённого и текущего холста. Подтверждайте только если это та же работа. Если настройки интерфейса изменились, выполните CALIBRATE, затем **Use Current Calibration**; физический размер холста должен остаться прежним.
6. Resume загружает оставшиеся траектории. Уже подтверждённые индексы заново не исполняются. STOP/F9 останавливает ввод, но контрольная точка 3.0 остаётся доступной в Projects.

**Roblox не восстанавливает холст по файлу проекта программы.** Если игра после выхода очистила рисунок и не умеет его загружать, продолжить на пустом холсте с середины нельзя: понадобится новый рисунок с начала. Не подтверждайте пустой/чужой холст. Приложение не нажимает игровые сохранение, удаление или переподключение автоматически.

Старый незавершённый запуск 2.0 хранился только в памяти: обновление не может восстановить его несохранённый индекс задним числом. Не закрывайте старый процесс ради обновления, если нужно закончить именно тот запуск.

Save As создаёт отдельную копию с текущим прогрессом, продолжение активного запуска остаётся в исходном проекте. Delete Checkpoint удаляет только журнал выполненных мазков выбранной работы, оставляя исходник и план; следующий запуск этой работы пойдёт с начала после подтверждения. Не нажимайте эту кнопку ради обычного продолжения.

## Smart Canvas Fill

Откройте Workspace → **Smart Canvas Fill**. Подсвечиваются только поля, добавленные геометрией размещения; настоящее белое платье или белый фон исходника не считаются пустотами.

| Режим | Результат |
| --- | --- |
| AUTO EXTEND | Продолжение ближайших краёв без внешней нейросети |
| BLURRED EDGES | Размытая расширенная подложка |
| SOLID COLOR | Подходящий цвет краёв изображения |
| MIRROR FILL | Зеркальное продолжение |
| REDLAIN BRANDING | Надпись REDLAIN только в добавленных полях |
| CUSTOM TEXT | Ваш текст, размер, цвет, Sans / Serif / Mono, выравнивание |
| PATTERN FILL | Линейный геометрический узор |
| NONE | Сохранить поля |

При тексте нажмите на добавленное поле в небольшом Preview, чтобы задать положение. Редактор обновляется автоматически; итоговый план нужно пересчитать кнопкой PREVIEW. Оформление включается в реальные пиксели **до** планирования и сохраняется в проекте. Слишком мелкие буквы могут потеряться на ограниченном игровом холсте — увеличьте размер и проверьте DRAW PREVIEW. AUTO EXTEND не придумывает отсутствующие части персонажа.

## Discover

Введите запрос или выберите тему. Результаты приходят из **Wikimedia Commons**, а не из набора демонстрационных картинок. Выберите карточку: увидите изображение, источник, автора/лицензию, оценку цветов/форм/мазков/времени и рекомендуемый режим. **Import to Workspace** переносит реальное загруженное изображение. **Save to Favorites** сохраняет его локально для доступа без интернета; **Open Original** открывает страницу источника. Surprise Me выбирает тему и выполняет настоящий поиск.

Оценка сложности использует локальный планировщик и текущий профиль; она не измеряет сервер Roblox заранее. Соблюдайте лицензию выбранного изображения. Поиск Commons не требует API-ключа. При недоступности интернета приложение показывает ошибку; избранное с уже загруженными файлами остаётся доступным. В этой облачной среде API Commons заблокирован сетевой политикой; для приложения на Windows требуется обычный доступ к `commons.wikimedia.org` и `upload.wikimedia.org`.

Необязательная генерация в Image / AI использует прежние AI SETTINGS и требует ваш ключ внешнего провайдера. Human, проекты, импорт, заполнение полей и локальный анализ работают без него.

## Если что-то пошло не так

F8 — пауза/продолжение, F9 — остановка. При потере окна, невозможности подтвердить кисть/цвет или рисунок включается автопауза. Верните нужный холст и прежнее окно/DPI, затем Resume. При другой геометрии приложение покажет требуемые и текущие размеры. Не понижайте проверки ради старта на неизвестном холсте.

Журнал событий: `%LOCALAPPDATA%\AnimeDrawer\logs\redlain-events.jsonl` (с ротацией). Диагностика цветов/полей/TEST DRAW остаётся в той же папке logs. Ошибка установки: `logs\startup.log` рядом с `run.bat`. При обращении укажите версию, профиль и приложите соответствующий журнал; API-ключ присылать не нужно.
