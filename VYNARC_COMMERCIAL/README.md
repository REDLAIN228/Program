# VYNARC — Cinematic Commercial (15 s)

**CREATE. CONNECT. ORGANIZE.**

Отдельный продакшн-проект 15-секундного рекламного ролика VYNARC: процедурная 3D-анимация на Three.js/GLSL, офлайн-рендер по кадрам в headless Chromium, HDR-композитинг, синтезированный звук, экспорт FFmpeg. Основной код репозитория (REDLAIN Draw Engine) не изменялся.

`previews/` — контактные листы, отчёт QA (`qa_report.json`), график непрерывности движения, спектрограмма звука с метками событий, быстрое превью 540p.

## Фирменный стиль и логотип

- Палитра из ТЗ: `#05030B` (пол чёрного в грейдинге), `#10091D`, `#8B3DFF`, `#B45CFF`, `#491A85`, `#C9C7D8`, `#F5F3FA`, `#92909F` — заданы в `animations/timeline.json` и `scenes/lib.js`. Оранжевый, красный и синий как акценты не используются; QA измеряет оттенки насыщенных пикселей готовых файлов.
- **Плоский логотип в финале — официальный PNG без изменений** (`assets/vynarc_logo_official.png`, только обрезка прозрачных полей → `vynarc_logo_trim.png`). Свет (блик, проявление) добавляется поверх по его собственной альфе. QA сравнивает финальный кадр с официальным файлом: корреляция ≈ 0,99.
- **3D-символ** построен экструзией контуров, снятых с альфа-канала официального PNG (`scripts/trace_logo.py` → `animations/logo_geometry.json`): два наклонных штриха (правый спереди, как в оригинале) и дуга — фронтальная часть эллиптической «орбиты», подогнанной по точкам дуги (центр ≈ центр V, наклон ≈ 67°). Пропорции и форма не придумывались. Словесный знак не набирается шрифтом: буква «Λ» в нём без перемычки, поэтому он используется только из официального PNG.

## Интерфейс

Исходного кода VYNARC в доступном репозитории нет (здесь лежит другой проект — REDLAIN Draw Engine), поэтому единственный источник интерфейса — присланный скриншот. Главный экран воссоздан в HTML/CSS 1:1 по раскладке 1672×941 с теми же текстами (`assets/ui/vynarc_ui.html`, сравнение — `references/ui_recreation_vs_screenshot.png`) и снят Playwright в 2,5× как прозрачные текстуры по компонентам (`assets/ui_textures/`, позиции — `layout.json`).

- Язык интерфейса — русский, как в приложении; слоганы — английские, как в сценарии.
- Логотипы сторонних продуктов со скриншота (Blender, After Effects, Roblox) заменены нейтральными иконками Lucide (лицензия ISC); названия проектов пользователя сохранены.
- Карточки сцены 3 и превью файла собраны из тех же данных (проекты, файлы, заметка «Идеи», связь «AE ↔ Референсы»).

## Технологии (реально запущенные)

| Задача | Инструмент |
|---|---|
| 3D, материалы, свет | Three.js r170 (WebGL2): PBR-металл `MeshPhysicalMaterial` + процедурное окружение PMREM, инъекции шейдеров (материализация, блик, изогнутые нормали для градиента по граням) |
| Шейдеры | GLSL: световые ленты, орбита, стеклянные панели (sheen, ободок, растворение), связи с импульсами, частицы, свечения, текст по буквам |
| Анимация | собственная библиотека `animations/easing.js`: cubic-bezier, затухающие пружины (инерция, контролируемый overshoot), Catmull-Rom траектории камеры, детерминированный шум |
| Композитинг | свой HDR-пайплайн `scenes/post.js`: motion blur накоплением субкадров (затвор 180°, 2–8 сэмплов по сложности), bloom (13-tap mip-цепочка), анаморфные блики, hue-preserving тонмаппинг, подъём чёрного до `#05030B`, виньетка, минимальная хроматическая аберрация, плёночное зерно, дизеринг против бандинга; DOF — через mip-bias текстур |
| Рендер | Playwright + headless Chromium (SwiftShader, без GPU), кадры по индексу, сырой RGBA по HTTP прямо в FFmpeg |
| Звук | numpy-синтез (`scripts/synth_audio.py`): суб-дрон, аккордовый пэд с открывающимся фильтром, свисты (STFT-фильтрованный шум), удары, металлический резонанс, UI-сигналы, райзер, свёрточная реверберация; 48 кГц / 24 бит; стемы в `audio/stems/` |
| Видео | FFmpeg: libx264 / libx265, AAC |

Не использовались, потому что их нет в окружении или они не дают выигрыша здесь: Blender (не установлен; Cycles на CPU для 4K60 был бы на порядки медленнее), GPU, GSAP/Remotion (покадровый детерминированный рендер проще и точнее через свою библиотеку кривых).

## Повторный рендер

Требования: Node.js ≥ 18, Python 3 с numpy и Pillow, FFmpeg с libx264/libx265, Playwright с Chromium (`npx playwright install chromium`, если его нет).

```sh
cd VYNARC_COMMERCIAL
npm install                      # three, lucide-static
scripts/render_all.sh            # всё: геометрия логотипа, UI-текстуры, звук, 3 формата, кодирование, QA
```

По шагам:

```sh
python3 scripts/trace_logo.py                       # геометрия символа из официального PNG
node scripts/build_ui.mjs                           # UI-текстуры из assets/ui/vynarc_ui.html
python3 scripts/synth_audio.py                      # audio/vynarc_sound.wav + стемы
scripts/render_format.sh landscape4k 3840 2160 0 2  # имя, ширина, высота, MSAA, число воркеров
scripts/render_format.sh portrait 1080 1920 4 2
scripts/render_format.sh square 1080 1080 4 2
scripts/encode_deliverables.sh                      # звук + все версии в renders/
python3 scripts/qa_check.py                         # отчёт previews/qa_report.json
```

Быстрые проверки:

```sh
node scripts/render.mjs --width 960 --height 540 --stills 2.8,5.9,9.0,14.0 --outdir previews/check
node scripts/render.mjs --width 960 --height 540 --step 2 --out previews/quick.mp4   # превью 30 к/с
```

Рендер возобновляемый: готовые чанки (`renders/chunks/<формат>/chunk_NN.mp4` + `.ok`) пропускаются. Каждый кадр — чистая функция времени, поэтому чанки можно считать на разных машинах. С GPU Chromium будет заметно быстрее; на 4 ядрах CPU без GPU 4K-мастер считался ≈ 2 ч.

Все тайминги событий (и звука, и анимации) — в `animations/timeline.json`; камеры — `cameraKeys()` в файлах `scenes/s1…s6`.

## Честные ограничения

- Звук проверен численно (уровни, спектрограмма с метками событий, совпадение атак с таймлайном ±50 мс), но не прослушан человеком — стоит послушать на мониторах и при желании поправить громкости в `build()` или стемы.
- Глубина резкости — аппроксимация через размытие текстур (mip-bias) для панелей и текста, а не физический DOF по буферу глубины.
- Карточки сцены 3 и превью `concept_art.png` — оформленные по стилю приложения композиции из его данных, а не снимки реальных экранов (их нет в исходниках).
- Если в настоящем приложении цвета или экраны отличаются от скриншота, достаточно поправить `assets/ui/vynarc_ui.html` и перезапустить `build_ui.mjs` и рендер.
