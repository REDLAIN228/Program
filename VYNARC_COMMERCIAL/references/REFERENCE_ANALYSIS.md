# Анализ референса и техническая карта сцен

Источник: `references/reference_video.mp4` (передан пользователем). Его название, логотип, интерфейс и музыка в рекламу VYNARC **не переносятся** — заимствуется только кинематографическая механика.

## Параметры референса (ffprobe)

| Параметр | Значение |
|---|---|
| Длительность | 13,000 с |
| Видео | HEVC 1920×1080, 30 к/с, ~0,84 Мбит/с |
| Звук | AAC 44,1 кГц стерео, 128 кбит/с, непрерывная музыкальная подложка |

## Метод

Кадры извлекались FFmpeg (4 к/с для контактных листов `references/reference_sheet_*.png`, все 390 кадров в 160×90 для метрик). По каждому кадру считались средняя яркость и средняя абсолютная разность с предыдущим кадром (мера скорости движения камеры/объектов); звук — RMS-огибающая по кадрам. Порог «склейки» — разность > 20.

Шкала скорости движения (средняя |Δ| яркости, 160×90): спокойный дрейф 1–3, движение камеры 5–10, хлыстовые переходы с motion blur 15–21, жёсткая склейка 35.

## Покадровая карта референса

| Время | Что происходит | Камера / движение | Свет / оптика | Переход |
|---|---|---|---|---|
| 0,00–1,50 | Большие мягкие светящиеся «шёлковые» ленты по диагонали; в центре прорисовывается знак-звезда, затем печатается словесный знак | медленный дрейф, Δ 1,5–7,5; яркость падает 86→35 по мере ухода форм вглубь | гауссово свечение, сильный bloom, тёплый монохром | морфинг: знак → ряд кнопок |
| 1,50–2,73 | Ряд «чипов» со светящимся контуром появляется по одному; курсор нажимает на «Code» | почти статична, Δ 1,4–2,6; лёгкий overshoot у чипов | контурное свечение + ореол | **жёсткая склейка 2,73** (Δ 35) в чёрное |
| 2,73–3,67 | Крупный текст запроса печатается по буквам | статика, Δ < 1 | свечение от верхнего края | масштабирование |
| 3,67–4,60 | Текст уменьшается в поле ввода, поле наклоняется в 3D | отъезд с ускорением, Δ 3→13 | волна света снизу справа | толчок вперёд |
| 4,60–5,20 | Строки кода летят навстречу | самый быстрый участок, Δ 15–21, направленный motion blur | — | пролёт сквозь объект |
| 5,20–6,70 | Карточка сайта в 3D (поворот по Y ~15–25°), всплывает и оседает | ease-out с мягким дотягиванием, Δ 2–7 | пик яркости 83 | хлыстовая панорама |
| 6,70–7,30 | Панорама вниз к полю ввода | Δ 15–19 | motion blur | — |
| 7,30–9,90 | Второй запрос, карточка вне фокуса сверху | медленный трекинг, Δ 3–6 | глубина резкости | панорама вверх + смена цвета |
| 9,90–11,50 | Карточка в новом цвете, 3D-дрейф | Δ 1–7 | — | уход в чёрное |
| 11,70–12,90 | Финальный знак пульсирует, буквы подписи прилетают по дуге с задержкой ~40 мс на букву | статика | ореол знака | удержание |
| 11,80–13,00 | Финальная карточка/чёрный, музыка продолжается | — | — | конец |

Звуковые акценты (пики RMS): 0,20 (старт), 1,50 (появление чипов), 2,70–2,80 (склейка), 4,70 (толчок), 5,70, 6,10, 6,67–6,80 (панорама), 9,0, 10,5–10,6, 12,0, 12,7–12,8. Удары совпадают с переходами с точностью до кадра.

## Что взято из механики и как адаптировано под VYNARC

| Механика референса | Где в рекламе VYNARC | Реализация |
|---|---|---|
| Мягкие диагональные «шёлковые» ленты света | 00:00–00:02 | `Ribbon` (гауссов профиль + яркое ядро + серебристый блик), две широкие тёмные ленты на фоне |
| Знак рождается из света | 00:02–00:04 | лента пружиной «садится» в дугу-орбиту логотипа; символ V материализуется шумовым фронтом с горячей кромкой |
| Пролёт сквозь объект с сильным motion blur | 03,3–04,1 и 06,5–07,2 | 8 субкадров затвора 180° + световая пыль, превращающаяся в штрихи |
| Чипы/карточки появляются по одному со свечением контура | 04,3–05,0 | стеклянные карточки Проекты/Файлы/Заметки/Референсы/Связи вылетают из хаба на пружине (контролируемый overshoot) |
| 3D-карточка, всплывающая и оседающая | 07,0–10,0 | компоненты главного экрана собираются послойно, карточки проектов выдвигаются вперёд, превью файла вылетает из списка |
| Расфокус второго плана | 07,4–08,8 | DOF через mip-bias текстур: интерфейс размыт за заголовком, затем перевод фокуса |
| Буквы финальной подписи прилетают по дуге с задержкой | 13,2–13,9 | каждая буква — отдельный квад, дуга + поворот + расфокус→резкость, шаг 26 мс |
| Удержание финальной карточки | 12,9–14,4 | логотип 1,5 с полностью, слоган ~1 с, затем мягкое затухание |

Отличие по ритму: референс длится 13 с с ~3 с «хвоста»; сценарий VYNARC задаёт 15 с и шесть сцен, поэтому темп переходов перенесён пропорционально, а самые быстрые участки (Δ 15–21) приходятся на пролёт сквозь дугу и на рывок к хабу.
