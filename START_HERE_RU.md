# Начните здесь — REDLAIN DRAW ENGINE 4.0

1. **Готовая сборка:** распакуйте папку `RedlainDrawEngine` целиком (вместе с `_internal`) и запустите `RedlainDrawEngine.exe`. Python не нужен.
   **Из исходников:** установите Python 3.11–3.13 x64 с python.org, распакуйте весь ZIP (например в `C:\REDLAIN`) и запустите `run.bat`. Первый запуск установит библиотеки; журнал ошибок — `logs/startup.log`.
2. Откройте **[инструкцию 4.0](V4_GUIDE_RU.md)**. Маршрут: Рисование → Импорт → «Весь холст / 100%» → режим BALANCED → профиль игры → TEST DRAW → PREVIEW → RUN.
3. Без Roblox всё можно проверить на встроенном холсте: Настройки → Инструменты → «Локальный тестовый холст» → TEST DRAW → PREVIEW → RUN.
4. Сохранение: **F8 / PAUSE & SAVE** → дождаться галочки ассистента или «Saved» → выход через меню иконки R. После запуска: Проекты → Resume. В игре должна быть открыта та же работа; пустой холст из контрольной точки не восстанавливается.
5. После обновления с 3.0 повторите **Настройки → Калибровка скорости · 4 линии**: в 4.0 выбранная скорость соблюдается точно, поэтому рука движется быстрее, чем раньше на той же ступени.

F8 — пауза/продолжение, F9 — остановка. Данные и проекты: `%LOCALAPPDATA%\AnimeDrawer` (прежнее имя папки сохранено, обновление их не трогает).

[Инструкция 4.0](V4_GUIDE_RU.md) · [отчёт и замеры 4.0](docs/V4_REPORT_RU.md) · [сценарий проверки Roblox](docs/WINDOWS_ROBLOX_TEST_RU.md) · [инструкция 3.0](V3_GUIDE_RU.md).

Сборка EXE — на Windows: `build.bat`. Результат — `dist\RedlainDrawEngine\`; переносите всю папку.
