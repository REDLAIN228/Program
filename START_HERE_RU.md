# Начните здесь

Это исходники программы, не готовый EXE. Запуск и рисование на встроенном холсте Windows подтверждены пользователем. Приём ввода непосредственно в Roblox ещё не проверен. Сначала проверьте программу на встроенном холсте.

## 1. Установка и запуск

1. Установите Python 3.11, 3.12 или 3.13 x64 с официального сайта python.org. При установке оставьте Python Launcher включённым или добавьте Python в PATH. Python 3.14+ пока не поддерживается.
2. Распакуйте ZIP полностью, например в папку `C:\AnimeDrawer`. Не запускайте файлы прямо из архива.
3. Откройте папку, где лежат `run.bat`, `main.py` и `requirements.txt`.
4. Дважды нажмите `run.bat`. При первом запуске нужен интернет: скрипт устанавливает библиотеки. Дождитесь завершения. При незавершённой установке следующий запуск снова попробует установить библиотеки.
5. При ошибке обновлённый `run.bat` оставляет окно открытым. Подробности сохраняются в папке `logs`, файл `startup.log`. Пришлите этот файл или текст ошибки. Если закрывается даже обновлённый скрипт, откройте папку в Проводнике, в адресной строке введите `cmd`, нажмите Enter и выполните `run.bat` в появившемся окне.

Библиотеки устанавливаются отдельно в `%LOCALAPPDATA%\AD\envs`. Это предотвращает ошибку PySide6 из-за длинного пути, когда папка `Program-...` вложена в ещё одну папку `Program-...`. Если запускаете старую версию и видите ошибку `No such file or directory` с длинным путём к PySide6, распакуйте архив заново в короткую папку, например `C:\AD`, чтобы файл запуска находился непосредственно в `C:\AD\run.bat`. Не переносите туда старую папку `.venv-win`.

## 2. Сначала тест без Roblox

1. Нажмите плавающую иконку, затем `TOOLS → LOCAL CANVAS`.
2. Нажмите `TEST DRAW` и подтвердите разрешение нарисовать тестовую линию. После появления линии подтвердите правильность результата.
3. Нажмите `CLEAR` в окне холста.
4. В программе нажмите `IMPORT IMAGE`. Для пробы есть файл `assets/sample_character.png`.
5. Выберите `Unlimited`, нажмите `PREVIEW`. Откройте вкладку `DRAW PREVIEW`: именно эти штрихи будут рисоваться.
6. Нажмите `RUN`. Программа должна сама рисовать на тестовом холсте. F8 — пауза, F9 — остановка.

## 3. Настройка в Roblox

Для текущей версии нужны постоянные видимые кнопки цветов и размеров кисти. Цветовой круг и ползунки автоматически не поддерживаются. Если у вашей игры только такие элементы, одной калибровки недостаточно — нужен адаптер под реальный интерфейс игры.

1. Откройте Roblox в оконном или безрамочном режиме. Подготовьте пустой белый холст. Поставьте непрозрачность кисти 100%.
2. Откройте палитру и кнопки кистей так, чтобы они оставались видимыми во время рисования.
3. В ANIME DRAWER нажмите `CALIBRATE`, выберите окно Roblox.
4. На снимке окна укажите два противоположных угла холста внутри рамки.
   Ошибочную точку можно отменить кнопкой «Отменить точку» или Ctrl+Z. Обязательные шаги отмечены цифрами: холст, цвета, размеры. Кнопка сохранения включится после их заполнения. Область персонажа нужна только для CAPTURE; при импорте картинки её отмечать не нужно.
5. Через `Кисть · инструмент` отметьте кнопку кисти, если её требуется выбирать.
6. Через `+ Цвет палитры` по очереди отметьте постоянные цветные кнопки. Подтверждайте цвет выбранного образца.
7. Через `+ Размер кисти` отметьте кнопки размеров. Указывается реальная толщина рисуемого следа в физических пикселях, а не произвольная цифра игрового ползунка. Если размер неизвестен, его нужно измерить по пробному следу на снимке экрана.
8. Если есть однотонный индикатор выбранного цвета, отметьте его через `Индикатор цвета`.
9. Сохраните профиль. Нажмите `TEST DRAW`, разрешите линию и проверьте результат в игре. Если линии нет или она не там, не подтверждайте калибровку: исправьте точки. Обычный ввод Windows может не приниматься игрой.
10. Очистите холст от тестовой линии. Нажмите `IMPORT IMAGE`, выберите картинку, затем `PREVIEW`. Проверьте изображение и оценку времени.
11. Выберите лимит, который действительно остался в раунде. Если оценка превышает лимит, RUN не запустится. `Auto` означает 165 секунд, а не распознавание таймера игры.
12. Нажмите `RUN`. Программа скроет свои окна, активирует Roblox и начнёт рисование. Не трогайте мышь и не переключайте окна. F8 — пауза/продолжение, F9 — остановка.

При изменении размеров окна, масштаба Windows или расположения элементов повторите калибровку. Потеря фокуса или перемещение окна во время рисования останавливают ввод.

Обычная картинка не требует API. Для превращения персонажа или текста в новое аниме-изображение нужен отдельно настроенный AI-провайдер; локальные фильтры не заменяют генерацию.

## 4. Сборка EXE

На Windows запустите `build.bat`. После успешной сборки EXE должен находиться в `dist\AnimeDrawer\AnimeDrawer.exe`. Переносите всю папку `AnimeDrawer`, включая `_internal`. Готового EXE в этом архиве нет.

Подробности и ограничения описаны в `README.md`.
